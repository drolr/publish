# 平台事实与限制

本文件只说明公开仓库的适配边界。私人现场观察与验收记录未发布，因此不在此复制真实门店、账号、文章、记录 ID、资源 URL 或截图。

巨懂车页面相关代码位于 `src/infrastructure/platforms/judongche/`。`tests/fixtures/judongche-pages/` 为手工整理的脱敏/合成片段，其他 fixture 使用受控页面和测试事件。它们可以证明算法和异常分类，无法证明所有真实页面版本或账号的行为。

公开组合根不包含特定门店确认和历史任务批准。无法确认门店、上下文、页面契约、上传完成或结果归属时，沿既有安全规则暂停。禁止根据 fixture 参数或相同标题推断真实平台成功，也禁止为使流程继续而弱化未知状态检查。
