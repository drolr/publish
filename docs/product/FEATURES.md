# 功能范围

当前代码包含以下模块，实际行为以源码与测试为准：

- Article Package 校验、文件/网络图片输入与本地资产持久化。
- 手工文章编辑、按顺序保存正文段落和图片、本地原创/转载声明。
- 文章列表、预览、分页、本机删除与修订。
- 本地封面配置与上传流程的受控适配边界。
- 单篇草稿、顺序批量、可见逐篇状态、停止和重启恢复。
- SQLite 编号迁移、重复执行保护、歧义任务的人工作业边界。

未来平台适配、通用 CMS、任意图片加工、AI 写作、定时无人值守发布和并行商家提交不属于当前范围。

本地声明不证明平台存在相同字段；平台提交不等于已保存并核对；离线 fixture 不证明真实页面兼容。
