# 发布范围与隐私说明

公开版本采用当前工程的已跟踪源码白名单，不包含原 Git 历史。保留源码、合成测试、SQL 迁移、脚本、CI、构建配置、依赖清单及锁文件。

## 排除范围

- 私人运行数据库、文章、图片、封面和平台浏览器会话。
- 日志、网络捕获、截图、诊断、安装备份、打包产物和依赖目录。
- Agent 工作记录和 `.superpowers` 临时审查材料。
- 原 `docs/process/` 的现场验收记录、真实文章/门店清单、截图资产。
- 原 `docs/superpowers/` 历史规格、计划及私人批准记录。
- 原产品与架构文档中混入的个人路径、账号/门店和现场接续状态。

上述历史文档未逐条公开；此处重新整理产品、架构和开发流程摘要，避免通过交叉链接泄露私人材料。需要继续私人部署工作时，应在本地查阅原始记录，不能把公开摘要当作历史审批凭据。

## 源码调整

`src/desktop/main/index.ts` 移除了私有门店绑定、已保存任务确认和历史恢复批准的组合参数。通用恢复机制和受控合成测试保留；公开版本遵循原有未知状态暂停规则，不会自动继承私人账号或历史任务的放行权限。

`tests/fixtures/library-historical-data.ts` 不再包含个人备份绝对路径，改为显式环境变量 `DRAFT_ASSISTANT_SCHEMA6_BACKUP`。未配置时不读取任何历史库，相关个人备份测试跳过；合成迁移测试保留。

`tests/integration/editor-upgrade.test.ts` 删除了依赖私人 schema2 备份、真实业务 UUID 和内容指纹的历史用例，保留合成升级测试。依赖同一私人备份的 `tests/e2e/continuous-editor-native.spec.ts` 也未发布。

`tests/fixtures/judongche-pages/README.md` 改写为 fixture 的公开用途与限制，去掉私人现场证据索引。其余 fixture 使用合成文章、门店和资源；测试中的 `secret`、`password` 等值是拒绝/脱敏测试数据。

## 提交前检查

`.gitignore` 只能阻止未跟踪文件被误加，无法删除已经提交的秘密。提交前仍需审查文件清单和差异，检查密钥、会话、个人路径、真实文章、账号/门店标识以及图片元数据。需要分享真实诊断时，先另行脱敏，再明确确定分享范围。

源码检查、离线测试和依赖审计分别报告；不将历史平台验收或本机安装结果外推为公开版本的新验证结果。
