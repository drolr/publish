# 架构与安全边界

依赖方向为 `renderer → typed bridge → application → domain ports ← infrastructure`。领域代码只依赖运行时中立契约，应用层不包含 SQL、选择器或 UI；基础设施实现端口，Electron main 显式组合依赖。

renderer 保持 `nodeIntegration=false`、`contextIsolation=true` 和 sandbox；不开放任意 IPC、文件系统、进程或浏览器接口。远程商家页面只在专用 Playwright 浏览器运行，不放入特权 renderer。

规范任务/批次状态保存在应用/领域与持久化层，React 本地状态只用于交互投影。批次按平台顺序执行；停止阻止新任务并在安全检查点生效。崩溃后的模糊在途任务不能自动重放。保存尝试、提交记录和已核对草稿是不同证据。

SQLite 存业务元数据，文章图片存应用管理的文件资产，浏览器会话独立保存。数据库修改通过编号、可复现、向前迁移完成。Cookie、密码、验证码和会话令牌不得进入业务表、日志或 Git。

平台选择器、URL、页面识别、图片与封面映射都封装在适配边界。遇登录失效、验证、风控、未知页面或保存结果不明时暂停并要求人工处理。不做验证码解决、反检测、身份验证绕过或后台私有接口替代。

架构检查通过脚本与测试机械执行。CI 仅使用临时数据和合成页面，不读取私人生产会话，也不创建真实草稿或发布内容。
